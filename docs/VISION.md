# Product vision

Varde is a mobile-first development command center, not a companion to a desktop IDE. Its primary audience is developers managing many products and delegating implementation to AI coding agents from a phone.

Core loop: design, delegate, monitor, review, validate, release.

A product may contain multiple repositories. GitHub remains the source of truth for code, issues, PRs, releases and workflows. Varde adds portfolio priorities, lifecycle stages, an attention inbox, idea incubation and agent handovers. A handover should include repository and branch, applicable AGENTS.md and CLAUDE.md, relevant issues, changes, CI errors and acceptance criteria. Direct agent integrations depend on supported provider APIs.

Principles: native Android, local-first, optional AI, no mandatory backend, no fabricated progress scores, explicit confirmation for consequential GitHub writes, no credentials in logs or exported briefs. Do not reinvent an IDE or issue tracker.
